# PowerShell Automation

PowerShell was used to demonstrate how repetitive Active Directory administration can be automated instead of performed manually through graphical management tools.

## Automation

PowerShell was used to:

- Create Active Directory users in bulk.
- Assign users to the appropriate Organizational Units.
- Configure account properties consistently.
- Add users to security groups.
- Reduce repetitive manual administration.

## Why Automate?

Creating a small number of users manually is manageable, but enterprise environments may require administrators to provision many accounts at once.

Automation improves:

- Consistency
- Efficiency
- Scalability
- Repeatability
- Reduction of manual errors

## Result

The lab demonstrates both graphical Active Directory administration and PowerShell-based automation for common identity management tasks.
