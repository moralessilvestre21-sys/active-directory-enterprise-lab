
# Active Directory Enterprise Lab

An enterprise-style Active Directory home lab built in VMware Workstation to simulate a real-world Windows domain environment.

## Technologies

- VMware Workstation Pro
- Windows Server 2022
- Active Directory
- DNS
- DHCP
- Group Policy
- PowerShell
- Windows 11 Client

## Objectives

- Deploy a Windows Server Domain Controller
- Configure Active Directory Domain Services
- Configure DNS
- Configure DHCP
- Join Windows clients to the domain
- Create Organizational Units
- Create Users and Groups
- Apply Group Policy
- Document enterprise design decisions
- Troubleshoot common Active Directory issues
